What I Learned About HTML This Week

This week I learned how HTML uses tags to describe the structure of a page. I built a profile page, a hobby page, and a study schedule table.

The most useful lesson was semantic HTML. Using header, main, and footer instead of only div makes my code easier to read and helps screen readers.
